Simon — the AI Apprentice

Hack-Nation × ElevenLabs · Capture → Map → Teach · Live: tacit-ai-apprentice.vercel.app · Code: github.com/Backpacked333/sorcerer-apprentice-

Challenge Tackled

  • Problem: a screen recording shows what an expert clicked, not why, when the rule stops applying, or who to ask. That judgment leaves with the person.
  • Users: the expert (shares screen, works real cases) and the new hire (works an unseen case with the expert's reasoning as tutor). Demo domain: accounts-payable invoices in a sandbox ERP.
  • Approach: an apprentice is a slot-filling machine, not a recorder. Each rule has empty slots (reason, limit, exception, who to ask). The screen shows when a judgment happened; voice fills a slot only at a pause. "Understood" = zero open slots plus the expert's explicit yes.
Capture
screen frames + ERP events → governor opens a question window at a pause → voice asks "why / limit / when stop"
→
Map
spoken debrief closes gaps; teach-back until expert says yes → confirmed Work Map (steps, verbatim quotes, guardrails)
→
Teach
new hire's field change triggers tutor before save; replays expert's screen moment; mastered vs. practice

What Worked Well

  • Timing is code, not a prompt. A deterministic governor decides when the agent may speak; in production tests, questions began in ~585–740 ms on one connection and closed gates stayed muted.
  • Honesty by construction: verbatim-or-nothing quotes, rules only where the expert stated the trigger, labeled fallbacks, consent-epoch "off the record" that strikes transcript, events, frames and clips.
  • Only a confirmed map teaches: tutor, save guard and exports load only maps with an expert confirmation.
  • Keyless mode runs the full loop (seed → Capture → Map → confirm → tutor → guard) as an end-to-end smoke test; 546 automated tests, typecheck and production build pass.

What Was Challenging

  • Voice reliability: background voices and agent echo triggered false answers. Fix: background-voice detection, a required log_answer tool confirmation, and discarding pre-listening transcript (false-quote bug P-12).
  • SDK drift: the installed ElevenLabs SDK dropped a VAD field and had a stale model enum; we override the wire payload and verify via read-back (agents:create --check).
  • Self-disconnect on timeout was mistaken for user hang-up; now an 8 s wait before a labeled browser-speech fallback.
  • Trust: masks painted before frames leave the browser; strict evidence-clock checks so one invoice's narration cannot satisfy another's.
  • Limits: human listening/real-room naturalness acceptance is still pending; we did not claim it.
