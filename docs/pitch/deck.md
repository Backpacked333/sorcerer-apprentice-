# Deck copy

Not a submission file. Seven slides for a finalist pitch, and the storyboard for the Tech video. Slide 7 is the closing frame of the Demo and Tech videos (`public/moonshot.svg`).

1. **We know more than we can tell.** An expert with decades in the seat, and a process document that covers half of the work.
2. **A recorder shows what. An apprentice asks why.** Knowledge is slots. Voice fills a slot only at a pause.
3. **Live demo.** The run of show in docs/05 §4, or the Demo video.
4. **How it passes the Apprentice Test.** Five rows, one screenshot each. docs/05 §5.
5. **One map, three readers.** The expert confirms it. The new hire is tutored from it. An agent loads it and stops where the expert would.
6. **What we measured.** Questions per 10 minutes, interruptions while typing, slots filled live versus in the debrief, pause to first word, intervention before save. Numbers from a real run. No invented percentages.
7. **People first, then agents, then a living memory.** The map an expert confirmed is the policy an agent can load. The agent runs the routine work and stops where the expert would. The only time it needs to ask is when nothing in the map matches.

Pitch line: We don't record how experts click. We learn when their decisions should change — and prove someone else can make them.
